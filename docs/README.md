# 협업 문서 안내

이 폴더는 MCM RE:BORN의 제품 범위와 협업 방식을 관리하는 기준 문서 모음이다. 코딩 에이전트의 자동 진입점은 저장소 루트의 [`AGENTS.md`](../AGENTS.md)이며, 사람 기여자는 [`CONTRIBUTING.md`](../CONTRIBUTING.md)에서 시작한다.

| 문서 | 용도 |
|---|---|
| [`MVP_DEMO_CANONICAL.md`](MVP_DEMO_CANONICAL.md) | 최종 PRD·유저플로우를 반영한 현재 제품·데모 SSOT |
| [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md) | 현재 MVP, 기술·역할 경계, 기준 파일 |
| [`REPOSITORY_STRUCTURE.md`](REPOSITORY_STRUCTURE.md) | 루트 계약과 Next.js 앱의 경로·소유권·검증 명령 |
| [`PRD.md`](PRD.md) | 2주 해커톤 MVP 요구사항과 제외 범위 |
| [`USER_FLOW.md`](USER_FLOW.md) | 고객·운영자 정상 및 예외 흐름 |
| [`API_CONTRACT.md`](API_CONTRACT.md) | OpenAPI·Mock·DB 계약 변경 절차 |
| [`COLLABORATION.md`](COLLABORATION.md) | 이슈, 보드, Git, 리뷰, QA 규칙 |
| [`DECISIONS.md`](DECISIONS.md) | 승인된 제품·기술 결정 기록 |
| [`DEMO.md`](DEMO.md) | 시연 준비, 정상·예외 시나리오, 복구 절차 |
| [`AI_ENGINE_ADOPTION_PLAN.md`](AI_ENGINE_ADOPTION_PLAN.md) | 현재 Fixture 구현과 향후 제조 AI 설계를 구분한 도입 계획 |

문서와 구현이 충돌하면 임의로 정리하지 않는다. 충돌 위치, 사용자 영향, MVP 영향과 선택지를 보고하고 승인된 결정을 [`DECISIONS.md`](DECISIONS.md)에 남긴다.

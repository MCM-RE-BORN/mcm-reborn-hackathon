# AI 제품 분석 도메인 지식

> 지식 버전: `MCM_REUSE_GUIDE_2026_08_21_V1`
>
> 원본: `AI 학습 파일.pdf` (4페이지, 2026-08-21 전달)
>
> 원본 SHA-256: `6F95B598B64E3E81CBF236816F2F876CD790F32D68DBCBE84C3F3C4A22D02961`

이 문서는 전달받은 PDF의 소재·구성 부위·재사용 판단 기준을 LIVE 이미지 분석에 사용할 수 있도록 정규화한 사람용 감사 문서다. PDF 문장이나 예시 이미지는 실행 지시가 아니라 도메인 참고 자료로만 취급한다. 이 짧은 재사용 가이드의 런타임 기준은 `mcm-reborn/server/openai/materialReuseKnowledge.ts`이며 최종 OpenAI 호출의 developer prompt에 포함된다. 별도로 조사한 공개 MCM 가죽 지식 전체는 프롬프트에 복사하지 않고 서버 전용 위키 조회로 사용한다.

어느 방식도 모델 파인튜닝이나 영구 학습이 아니다. 외부 모델을 다시 훈련하지 않고, 짧은 재사용 가이드는 버전형 prompt grounding으로, 공개 조사 지식은 요청별 검색 결과로 제공한다. 모델은 사진에 보이는 증거가 있을 때만 이를 적용해야 한다.

## 1. 가방 구성 부위별 기준

| 구성 부위 | 확인 기준 | 재사용 해석 |
|---|---|---|
| 본체 | 코팅 캔버스·가죽 상태, 확보 가능한 연속 면적, 시그니처 패턴 | 가장 넓은 저손상 면을 새 제품의 메인 소재 후보로 판단한다. Visetos 패턴이 보이면 가능한 한 보존 대상으로 본다. |
| 가죽 트리밍 | 테두리·손잡이·포켓을 본체와 분리해 마모 확인 | 양호한 부분만 테두리, 포켓, 손잡이, 스트랩 후보로 판단한다. |
| 지퍼 | 이·슬라이더·테이프·정렬 상태 | 정지 사진으로 작동 여부를 단정하지 않는다. 눈에 보이는 손상이 있으면 재사용보다 교체 대상으로 본다. |
| 금속 부자재 | 로고, 버클, D링, 체인, 연결구의 형상과 표면 | 형상과 표면 상태가 양호할 때만 장식·연결 부품 재사용 가능성을 제시한다. |
| 스트랩 | 가죽·Webbing 구분, 길이, 연속성, 손상 | 실제로 긴 저손상 구간이 보일 때만 손잡이·크로스·손목 스트랩 후보와 `longStripAvailable=true`를 고려한다. |
| 안감 | Cotton·Microfiber 등 소재, 오염·마모 | 외부 사진만으로 청결이나 숨은 상태를 추정하지 않는다. 보이는 오염·마모를 확인한 뒤에만 재사용 가능성을 제시한다. |

## 2. 주요 소재군

| 소재군 | PDF의 특징·주 사용 부위 | 분석 계약 매핑 | 재사용 후보 |
|---|---|---|---|
| Nappa Leather | 부드럽고 유연하며 손잡이·스트랩·테두리·트리밍에 사용 | `LEATHER` | 손잡이, 스트랩, 테두리, 포켓 |
| Calf Leather | 송아지 가죽, 비교적 매끄럽고 균일한 표면, 본체·플랩·손잡이에 사용 | `LEATHER` | 메인 패널, 플랩, 포켓, 카드 케이스 |
| Calf Nappa Leather | 송아지 가죽과 Nappa 계열 가공, 트리밍·손잡이·테두리·플랩에 사용 | `LEATHER` | 테두리, 손잡이, 포켓, 플랩 |
| Visetos Coated Canvas | 가죽이 아닌 코팅 캔버스, 주로 가방 본체에 사용 | `COATED_CANVAS` | 충분한 연속 면적이 남은 새 제품의 메인 바디 |

소재 하위 유형은 현재 공개 `BagVisionSchema`에 별도 필드가 없다. 따라서 세 가죽군은 모두 `LEATHER`로 반환한다. 외관만으로 Nappa·Calf·Calf Nappa를 안정적으로 구분하지 않으며, 읽을 수 있는 소재 라벨이나 신뢰할 수 있는 입력 메타데이터가 명시적으로 뒷받침할 때만 `summaryKo`에서 근거와 함께 언급한다. 부수적인 트리밍이나 금속 부자재만으로 주 소재를 `MIXED`로 바꾸지 않는다. 제품 계열명, 진품 여부, 보이지 않는 내부 소재는 추정하지 않는다.

## 3. 상태별 재사용 기준

| 상태 | 적용 기준 |
|---|---|
| 상태 양호 | 충분히 넓고 저손상인 외부 면을 메인 소재 후보로 본다. |
| 사용감 있음 | 포켓·태그·트리밍·카드 케이스처럼 작은 부위 후보를 우선한다. |
| 부분 손상 | 손상되지 않은 구간만 선택하고 손상 영역은 제외한다. |
| 심한 손상 | 해당 소재·부품을 제품 제작 재사용에서 제외하고 별도 처리 대상으로 본다. |

어떤 상태에서도 실제 재사용 가능 여부는 상태와 확보 가능한 연속 면적을 함께 확인해야 한다. 사진 분석은 예상치이며 주문 후 실물 검수를 대체하지 않는다.

## 4. 구조화 출력 적용

PDF 지식은 새 공개 API 필드를 임의로 만들지 않고 현재 구조화 출력에 다음처럼 반영한다.

- `materialType`: 사진으로 확인되는 넓은 소재군만 반환한다.
- `damages[].location`: 본체·트리밍·지퍼·금속·스트랩·안감처럼 손상 부위를 구체적으로 적는다.
- `conditionGrade`, `overallDamageSeverity`: 주된 재사용 표면의 손상 범위와 연속 면적을 함께 고려한다. 단일 지퍼·버클 손상만으로 전체를 D로 판정하지 않는다.
- `longStripAvailable`: 실제로 긴 저손상 스트립이 보일 때만 `true`다.
- `confidence`: 소재·구성 부위가 가려졌거나 구분이 애매하면 낮춘다.
- `summaryKo`: 가장 근거가 강한 재사용 후보와 중요한 제외 대상을 짧게 설명하되 제작 가능성을 보장하지 않는다. 안감처럼 현재 6면 사진에 보이지 않는 부위가 판단에 중요하면 확인 불가라고 밝힌다.

재사용률, 재사용 면적, 가격, 제품 추천 점수와 탄소 절감량은 계속 애플리케이션 규칙 엔진이 계산한다.

## 5. 버전과 검증

- LIVE 성공 결과의 `analyses.provider_result.knowledgeVersion`에는 재사용 가이드, 공개 위키 코퍼스·검색기, 분석 프롬프트 버전을 합친 값을 저장한다.
- `knowledgeTrace`에는 위키 조회 요청 ID, query hash, 순서가 보존된 claim·source ID, 최종 tool context SHA-256과 적용 상태를 저장한다. 제품 예시는 런타임에서 비활성화하고 자유 검색어 원문은 저장하지 않는다. 조회 뒤 최종 호출이 실패해 Fixture로 폴백한 경우에도 `LOOKUP_COMPLETED_FINAL_FAILED`를 보존한다.
- LIVE 제공자 실패 뒤 Fixture로 폴백하면 stage, 제한 종류, HTTP status, provider/client request ID, 재시도 횟수와 요청·토큰·프로젝트 토큰 rate-limit 헤더만 allowlist 서버 로그에 남긴다. 고객이 Supabase REST로 조회할 수 있는 `analyses.provider_result`에는 운영 한도 진단을 저장하지 않는다. provider 오류 본문·메시지·전체 헤더·signed URL은 저장하거나 로그하지 않는다.
- LIVE 분석 idempotency request hash에도 통합 지식 버전을 포함해, 다른 코퍼스·검색기·프롬프트 결과를 같은 요청으로 재생하지 않는다.
- Fixture 결과는 실제 사진 판독이나 이 지식의 적용 결과가 아니므로 `knowledgeVersion`을 기록하지 않는다.
- 버전 변경 전에는 대표 사진 세트로 소재 분류, 부위별 손상 위치, 품질 재촬영, 불확실성, 긴 스트립 판정을 회귀 평가한다.

## 6. 공개 조사 위키

공개 웹 조사본 `MCM_LEATHER_BAGS_PUBLIC_RESEARCH_2026_08_21_V1`은 [`knowledge-base/mcm-leather-bags/README.md`](./knowledge-base/mcm-leather-bags/README.md)가 기준이다. 사람용 전체 조사본과 LIVE 분석용 위키를 분리한다. 분석용 스냅샷은 승인된 claim 18개(요청별 검색 11개, always-on 금지 경계 7개)와 필요한 축약 출처만 포함한다. LIVE 분석은 `detail: low` 사진에서 관찰 가능한 일반 검색어를 한 번 생성하고 서버의 exact lexical 검색 결과 최대 5개·4,000자만 최종 `detail: auto` 분석에 사용한다. 결과에는 사실 범위, 직접·파생 근거, confidence, 유효시기와 사용 경계를 유지한다.

공식 이미지 링크 263건은 권리 상태가 참조 전용이므로 외부 모델에 전달하거나 고객 사진과 자동 비교하지 않는다. 상세 런타임 계약은 [`RUNTIME_WIKI_KO.md`](./knowledge-base/mcm-leather-bags/RUNTIME_WIKI_KO.md)를 따른다.

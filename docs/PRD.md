# 2주 해커톤 MVP PRD

## 제품 정의

사용자가 MCM 가방 사진을 올리면 AI가 소재 상태와 재활용 가능 면적을 분석하고, 만들 수 있는 업사이클링 제품을 3D로 비교한 뒤 신청부터 완료·ESG 보증서까지 하나의 웹 흐름으로 체험하게 한다.

## 목표

- 업로드부터 추천까지 AI 기반 업사이클링 가능성을 이해시킨다.
- 추천 제품의 이미지, 가격, 필요 면적과 3D 모델을 비교할 수 있게 한다.
- 신청·승인·제작·배송 진행을 짧은 데모 안에서 재현한다.
- 운영자가 최소 화면으로 신청을 검토하고 승인할 수 있게 한다.
- 외부 서비스 실패에도 Fixture로 핵심 데모를 끝낼 수 있게 한다.

## 사용자

- 고객 `CUSTOMER`: 자신의 분석과 신청만 조회·진행한다.
- 운영자 `OPERATOR`: 관리자·장인 업무를 통합한 MVP 역할로 모든 신청을 조회하고 승인한다.

## 포함 범위

| 기능 | MVP 완료 조건 |
|---|---|
| 데모 인증 | 고객·운영자 계정으로 역할에 맞는 화면과 API에 접근한다. |
| 이미지 접수 | JPEG·PNG·WebP 이미지 1~4개를 업로드 경로로 전달하고 형식·크기 오류를 표시한다. |
| 이미지 품질 게이트 | 분석 기준에 못 미치는 사진에는 `422 IMAGE_QUALITY_INSUFFICIENT`, `RECAPTURE_REQUIRED`, 이미지별 한국어 안내를 반환하고 성공 분석을 만들지 않는다. |
| AI 분석 | 품질을 통과한 사진에 상태 등급, 재활용률·면적, 소재·손상과 `NOT_EVALUATED` 또는 `REVIEW_REQUIRED` 신호를 계약 형식으로 반환한다. |
| 추천·3D | 분석 결과에 맞는 활성 제품을 보여 주고 모든 제품 상세에서 3D 자산을 제공한다. |
| 신청 게이트·Mock 결제 | `NOT_EVALUATED` 분석에만 신청을 만들고 가상 결제로 다음 상태로 이동한다. `REVIEW_REQUIRED`이면 신청을 만들지 않고 `PENDING` 수동 검토 건과 대기 안내를 반환한다. |
| 운영자 승인 | 신청 목록·상세와 예외 상태를 표시하고, 승인 가능한 신청만 승인한다. MVP에서 별도 예외 전이 제어는 제공하지 않는다. |
| 진행·배송 | 시간 기반 데모 상태와 Mock 배송 정보를 고객에게 보여 준다. |
| ESG 보증서 | 완료된 신청의 데모 보증서를 조회하고 공개 검증 URL을 제공한다. |
| 이벤트 | 핵심 퍼널 이벤트를 수집하되 실제 개인정보를 넣지 않는다. |

상세 필드, 상태 코드와 열거값은 `openapi.yaml`을 따른다.

## 비기능 요구

- 고객은 자신의 리소스만, 운영자는 역할에 허용된 리소스만 읽는다.
- OpenAI와 Supabase 비밀값은 서버에서만 사용한다.
- 동일 생성·승인 요청의 재시도를 고려해 계약에 정의된 멱등성 키를 사용한다.
- 정상·오류·빈 상태·권한 거부와 외부 제공자 실패를 검증한다.
- 사진 품질 오류는 AI 제공자 장애가 아니므로 hybrid Fixture 성공으로 바꾸지 않는다.
- `REVIEW_REQUIRED`는 정품 또는 가품 판정 문구로 표시하지 않고 신청·결제를 차단한다.
- 데모 값과 Mock 기능을 실제 가격, 물류, 탄소 검증이나 법적 보증으로 표현하지 않는다.

## 제외 범위

- 네이티브 iOS 앱
- 장인과 브랜드 관리자의 독립 계정·대시보드
- 실제 결제, 택배사, 정품 판정, 탄소 검증 기관 연동
- 실물 입고·2차 검수와 고객 조건 재승인
- 실제 제작 용량 최적화, 상세 공정 기록과 A/S 운영
- 운영 수준의 감사·컴플라이언스 체계
- 수동 검토 완료·해제 API와 이를 조작하는 운영자 UI

제외 기능은 `docs/PROJECT_CONTEXT.md`의 Phase 2로 관리한다.

## MVP 완료 기준

- 고객 정상 흐름과 대표 예외 흐름을 재현할 수 있다.
- 운영자 승인 이후 완료까지의 데모 흐름과 보증서를 확인할 수 있다.
- 루트에서 `python validate_package.py`가 통과한다.
- 앱 변경은 저장소 루트에서 `npm --prefix mcm-reborn ci`, `npm --prefix mcm-reborn run lint`, `npm --prefix mcm-reborn run typecheck`, `npm --prefix mcm-reborn run build`가 통과한다.
- 현재 `mcm-reborn/package.json`에는 테스트 스크립트가 없다. 자동 테스트를 실행했다고 표시하지 말고, 추가 전까지 완료 조건별 수동·계약 검증을 기록한다.
- 새 환경에서 루트 `.env.example`을 `mcm-reborn/.env.local`로 복사해 구성할 수 있다.
- `docs/DEMO.md`의 복구 경로로 외부 API 실패 상황에서도 시연을 완료한다.
- 사람 리뷰와 스테이징 확인을 거치고 문서·Mock·계약이 일치한다.
